# Student Marks Prediction using Machine Learning

## Project Overview

This is a beginner-level Machine Learning project that predicts student marks based on the number of study hours using Python.

## Objective

The objective of this project is to understand how Machine Learning can be used to predict marks from study hours.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

## Dataset

The project uses a small sample dataset containing study hours and corresponding marks.

## Algorithm

Linear Regression is used to train the model and predict student marks.

## Project Workflow

1. Create a sample dataset.
2. Prepare the input and output data.
3. Train the Linear Regression model.
4. Predict marks for 5 study hours.
5. Visualize the data and prediction line using a graph.

## Sample Prediction

The model predicts marks for a student who studies for 5 hours. The prediction is based on the sample dataset and is for learning purposes only.

## How to Run

1. Open the `Student_Marks_Prediction_ML.ipynb` notebook in Google Colab.
2. Run each code cell in order.
3. View the prediction and graph.

## Conclusion

This project demonstrates the basic workflow of a Machine Learning model using Linear Regression.
